# 如意 Ruyi 管理员手册

## 安装与版本选择

Ruyi for Mac 面向 Apple Silicon，部署目标为 macOS 14。核对同批 DMG 的 SHA-256，将完整 App 拖入「应用程序」，推出镜像后启动。内部试用包采用 ad-hoc 签名。首次打开时，按系统依据设备策略提供的选项确认来源。

| 版本 | 随包能力 | 默认业务数据目录 |
| --- | --- | --- |
| Ruyi Full | Node 工作台、ripgrep、Python、Office/PDF、Chromium 和桌面自动化 | `~/.ruyi-workbench-full` |
| Ruyi Slim | Node 工作台、ripgrep、原生宿主 | `~/.ruyi-workbench` |

两个版本均需配置模型。云端模型需要网络，本机或内网模型须先启动服务。系统浏览器模式可以交接网址；要控制网页内容，Full 中选择内置浏览器。

## 配置引擎与工作区

在设置中选择模型服务，填写端点、协议、模型和凭据，测试连接后发送一条简短消息。支持 Anthropic Messages、Chat Completions 和 Responses，协议要与服务端一致。使用 Claude Code 时先安装并登录本机 CLI，可在设置中指定可执行文件。已保存会话会记住引擎。遇到引擎不可用，在线程中重新选择引擎再继续。

为每个任务选择实际工作文件夹。按所需范围启用读取和写入，在多用户 Mac 上分别使用各自账户的数据目录和钥匙串。需要独立运行环境时，可用 `RUYI_HOME` 指定数据根。每个运行中的实例应独占其数据根。

## 权限、凭据与审计

在应用菜单「桌面权限」查看授权状态。执行桌面输入需要辅助功能，截图和屏幕 OCR 需要屏幕录制，语音输入需要麦克风。本地图片 OCR 可直接读取已授权的文件。Full 与 Slim 的系统权限分别登记，更换 App 后按诊断结果复核。

通过设置页的凭据输入框配置密钥。加密凭据受钥匙串保护。跨账户迁移时使用带密码的凭据恢复包，或在新账户重新填写。外部机器人绑定具体发送者和会话，在本机核对共享范围后启用。工作台的审计记录可用于核查工具调用、权限决定和任务结果。共享日志前检查路径、请求内容及凭据。

## 升级、回退与排障

保存任务并用 ⌘Q 退出所有使用该数据根的实例。关窗可能仍会在后台运行。升级采用整包替换。需要能够回退业务数据时，在实例退出后保存该数据目录的一致副本，并单独保管凭据恢复包。数据目录以外的工作文件夹、系统授权和钥匙串各自管理。

替换后从「应用程序」启动新版，核对工作区、历史消息、附件和必要的桌面能力。若需回退，退出新版，将升级前数据恢复到独立目录，指定该目录启动相应旧版。卸载时退出并移走 App，业务数据保留在用户目录。

无法连接模型时先核对服务地址、模型名、协议和鉴权。桌面工具缺失时先核对发行变体，再检查系统授权。帮助菜单提供应用内日志与操作手册。日常使用见[用户手册](USER-GUIDE_CN.md)。
